# Trang giới thiệu Côn Bằng TV

Mã nguồn của trang <https://conbangtv.github.io> — các tệp HTML tĩnh và ảnh trong `assets/`, đăng bằng GitHub Pages từ nhánh
`main`:

- `index.html` — trang giới thiệu (cài đặt, tính năng, nền tảng, «Cài trên Mac» `#cai-mac`). Ảnh các bước mở lần đầu trên Mac
  (hộp chặn, «Vẫn mở», «Mở») trong `assets/mac/` — chụp thật trên macOS 14 tiếng Việt, cắt sát hộp thoại, không có thông tin máy.
- `huong-dan.html` — hướng dẫn sử dụng: người xem / mã PIN / trẻ em, trang chủ, theo dõi, tìm kiếm, DNS / vượt chặn / proxy,
  menu khi xem phim. Ảnh chụp từ bản Android TV chính thức trong `assets/hd/` (JPEG 1280×720). App đổi giao diện hay tên mục
  thì sửa trang này theo, và đổi dòng «Theo bản …» ở đầu trang.

- App và mã nguồn: <https://github.com/Circling5714/ChimToTV>
- Cài trên Android TV: mở app Downloader, nhập mã `9192365`.
- Liên hệ: Telegram [t.me/tivikit](https://t.me/tivikit)

Sửa trang: sửa tệp HTML rồi đẩy lên `main`; GitHub Pages tự đăng lại sau khoảng một phút.
